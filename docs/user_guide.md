# 使用指南：桌面程序

本文说明如何启动 BOUNDYR 桌面程序，以及每一页是做什么的。安装和环境要求见 [README](../README.md)。

> 界面基于 Windows 工程机设计。真正调用 CFD 的功能（采样、主动学习）只能在装有 ANSYS CFX、CFturbo
> 的 Windows 电脑上使用；在其他系统上可以打开界面、查看已有结果、运行离线测试。

## 启动

- Windows：双击 `launch_gui.bat`。它会依次寻找项目自带的虚拟环境、系统里的 Python，
  然后安装依赖并打开程序。找不到 Python 时会提示，请先安装 Python 3.11 或更新版本并加入 PATH。
- 任何系统：在装好依赖的环境里执行 `python -m impeller_app`。

界面支持中文和英文，可在界面中随时切换语言，导航、标题和提示一起变化。

## 一次完整优化的流程

界面左侧是按顺序排列的工作流，用 `Ctrl+1` 到 `Ctrl+6` 可以快速切换：

| 页面 | 快捷键 | 作用 |
|---|---|---|
| 环境 | Ctrl+1 | 填写各软件、模板和工作目录的路径，并检查是否可用 |
| DOE | Ctrl+2 | 初始采样：在设计范围内均匀取一批点，交给 CFD 计算，得到第一批训练数据 |
| 主动学习 | Ctrl+3 | 训练预测模型，并反复挑选最值得验证的新设计去算，使模型越来越准 |
| 帕累托 | Ctrl+4 | 计算并查看"效率与压比最优折中"的设计集合，从中选点 |
| Sobol 分析 | Ctrl+5 | 分析各个几何参数对结果影响有多大 |
| 导出 | Ctrl+6 | 把选定的设计导出成可直接在 CFturbo 中打开的算例 |

另外三页用来看结果，不会触发任何计算：

| 页面 | 快捷键 | 作用 |
|---|---|---|
| 实时结果 | Ctrl+7 | 任务运行时查看进度、已完成样本数、当前最高效率和压比 |
| 数据分析 | Ctrl+8 | 筛选数据、画散点图、对比模型预测与 CFD 实际值 |
| 算例浏览 | Ctrl+9 | 逐个翻阅已算过的算例，查看输入、结果、日志和图片 |

### 第 1 步：环境

在"环境"页填写 PowerShell、几何脚本、CFX 的 `bin` 目录、各类模板文件、训练数据 CSV 和 CFX 使用的核数，
然后点"校验环境"。程序会逐项检查文件是否存在、能否调用。如果训练数据 CSV 还不存在，校验时会自动建一个空表。

你所做的修改会自动保存，下次启动时自动读回。默认的配置文件在 `%APPDATA%\BOUNDYR\impeller-app-config.json`。
也可以用环境变量 `IMPELLER_APP_CONFIG` 指定另一个配置文件，例如用于独立的实验阶段。
`windows-app-config.template.json` 是一份写满示例路径的清单，可以照着核对。

### 第 2 步：DOE（初始采样）

设定初始样本数、目标样本数和各几何变量的范围，点"启动 DOE"。程序会在范围内均匀取点，先用几何规则过滤掉
明显不合理的设计，再逐个调用 CFturbo、TurboGrid 和 CFX 计算。

- 出口静压是一个固定的工况值（默认 12 Pa），整个 DOE 和主动学习共用同一个，不再作为可调范围出现。
- 页面下方可以展开"默认工程参数"，修改流量、效率、功率等判定阈值和几何限制。
- 如果上次中断了，"恢复运行结果"会扫描已有的运行目录，重新提取结果并重建训练数据表，
  不必从头再算。已经保存的追加样本也会保留。

### 第 3 步：主动学习

- "训练代理模型"：用现有数据训练一个能快速预测效率、压比和流量的模型。
- "运行主动学习"：反复执行"预测 → 挑选新设计 → CFD 验证 → 更新模型"。可设置额外迭代次数。
- "恢复检查点"：从上次保存的位置接着往下做。
- "仅 DOE 的 NSGA-II 基准"：只用初始采样数据（不用主动学习积累的样本）训练模型并做一次优化，
  作为对照。它的模型单独保存，不会覆盖主动学习的模型。

挑选新设计的原则、记录哪些验证数据、失败的算例如何处理，见 [主动学习说明](active_learning.md)。

### 第 4 步：帕累托

点"计算帕累托前沿"后，会得到效率与压比之间的最优折中设计集合，并按工程指标给每个设计打分排序。
你可以按序号选点，也可以输入想要的效率或压比让程序找最接近的设计，或者按曲线位置取点。

### 第 5 步：Sobol 分析

在固定叶片数的情况下，估计每个几何参数对结果的影响程度，帮助判断哪些参数值得精细调整。
分析基于当前的预测模型，不会调用 CFD。

### 第 6 步：导出

选择要导出的设计数量和目标目录，程序为每个设计建一个文件夹，必要时附上 CFturbo 工程和批处理文件，
方便在 CFturbo 里重新生成几何。

## 查看结果的三个页面

### 实时结果（Ctrl+7）

启动后台任务时会自动跳到这一页。页面每 3 秒检查一次已保存的数据，也可以手动刷新或暂停自动刷新。显示内容：

- 已记录的样本数、目前最高的效率和总压比。
- 效率—总压比散点图：每个点是一个已完成的 CFD 样本。它不是经过筛选的帕累托前沿。
- 最近 200 条记录，以及真实 CFD 超体积（HV，衡量前沿好坏的综合指标）与模型预测 HV 的变化曲线。两者分开标注。

注意：单个算例还没算完时，页面不会给出估算的中间结果；HV 要等一轮迭代完整结束才更新。
这一页只读取已保存的文件，不会启动求解，也不会改动训练数据。DOE 与主动学习的数据分开显示，不会混在一起。
缺少来源信息的历史记录会显示"不可用"，而不是被悄悄归到当前实验名下。

### 数据分析（Ctrl+8）

- 按 DOE / 主动学习数据池、是否边界样本、叶片数筛选，对效率、总压比、流量、功率画散点图。
- 连续几何变量之间的相关性；叶片数按组统计。相关性只是描述性的，不能代替 Sobol 分析。
- 对比"CFD 之前的预测"与"CFD 实际值"，显示误差和模型自己给出的不确定度。没有记录的量不会被补造。
- 不同验证方式下的交叉验证记录分开显示。
- 图可以滚轮缩放、框选放大、双击复原；图上最多显示 5000 个点，但统计和导出用的是全部数据。
  表格可以搜索、排序，并把当前筛选结果导出。

### 算例浏览（Ctrl+9）

- 分别列出 DOE 和主动学习的算例，也包括目录已丢失、只剩记录的算例，以及没有登记的目录。
- 可以按来源、状态、关键字筛选。
- 每个算例显示输入参数、记录的结果和失败原因，以及当前结果文件是否仍然有效。
- 可以预览文本、日志、JSON 和图片，也可以一键打开所在文件夹。预览只读，不会运行任何求解器文件。

### 查看另一个实验的结果

"打开结果配置…"可以载入另一份配置（例如某个历史实验阶段）来查看它的数据，只影响"数据分析"和"算例浏览"两页，
不改变正在运行的任务和已保存的设置。"查看当前工作区"可回到当前配置。

这两页每 15 秒自动刷新一次，可以暂停；切换配置后不会收到旧配置的迟到数据。
数据缺失、损坏或口径不一致时会明确提示，而不是自动拼接或补全。

## 命令行工具

大部分功能在界面里就能完成。以下脚本适合批量处理或脱离界面使用：

| 脚本 | 用途 |
|---|---|
| `python prepare_al_stage.py --name <名称>` | 为一次独立的主动学习实验建立新的工作阶段 |
| `python final_checkpoint_evaluation.py --output-dir <目录>` | 重新训练并评估模型，不跑 CFD，结果不覆盖现有模型 |
| `python pareto_front_query.py ...` | 在帕累托前沿上按序号、目标值或曲线位置选点 |
| `python pareto_export_cft_cases.py ...` | 把帕累托点导出成 CFturbo 算例 |

各脚本的全部参数可加 `--help` 查看。
