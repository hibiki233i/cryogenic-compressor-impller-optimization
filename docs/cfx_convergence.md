# CFX 收敛检查与自动续算

一个算例"算完了"不等于"算好了"。本文说明程序如何判断一个 CFX 结果是否可信，以及没达标时如何自动续算。
所有经过 `cfx_runner.py` 的采样、主动学习和恢复流程都遵守同一套规则。

## 判断是否收敛

在做后处理之前，程序先检查**最新一份输出文件（`.out`）里最后一轮迭代的均方根残差**。
不看最大残差，也不用更早某一轮的低残差来代替。

- 需要同时具备并且有限的残差项：三个方向的动量、压力—质量、能量、湍动能、湍流频率。
- 每一项都必须**严格小于 1e-4**。刚好等于 1e-4 也不合格。
- 输出文件没有正常结束、缺少残差，或者找不到同名的 `.res` 结果文件，都不会被当作成功样本。

## 没达标怎么办：自动续算

第一次求解结束后若仍未达标，程序直接用对应的 `.res` 文件作为起点接着算（不需要已被清理的 `.def`）：

- 每批最多追加 500 次迭代，总共最多追加 1500 次。
- 每批结束后重新检查，一旦达标立刻进入后处理。
- 续算时，目标残差设为验收阈值的十分之一，避免求解器在验收线上"擦边"提前停下。
- 每次启动使用单独的输出名称，只监控、只终止本次启动的求解进程，不影响其他任务。
- 入口或出口任一边界连续三次迭代都报告"面积 100% 被占用"，按**堵塞**处理并终止。

追加预算保存在运行目录的 `cfx_convergence_state.json` 里，每批开始前先预留。
中途取消或出错不会"找回"预算；如果上次有一批没有完整结束，需要人工检查，程序不会擅自继续追加。
旧版本留下的续算记录会折算进总预算；已经由人工标记为"无效"的算例（`DOE_INVALID.json`）会被尊重，
只有标记之后新算出的收敛结果才能解除。

## 1500 次用完仍未达标

结果标记为"残差未收敛"：

- 保留输出文件、结果文件和审计信息。
- 旧的性能结果移到 `rejected_results/`，并写入 `CFX_INVALID.json`。
- 这个点**不进入**样本库，也不会触发"重复失败复核"。
- 这是**数值上不合格**，不作为"几何或物理上不可行"的负面样本去训练分类器。

## 成功之后

程序从最终的 `.res` 重新提取结果，并把最终输出文件的指纹和结果文件的特征写进元数据。
已缓存的结果文件即使格式正确，也必须先通过对应的收敛和"是否过期"检查才可以重复使用。

## 可调设置

配置文件（以及界面保存的设置）里有三项，会同时作用于采样和主动学习：

| 设置 | 默认 | 说明 |
|---|---|---|
| `cfx_residual_threshold` | 0.0001 | 残差验收阈值 |
| `cfx_max_extra_iterations` | 1500 | 最多追加的迭代总数，不得超过 1500 |
| `cfx_restart_chunk` | 500 | 每批追加的迭代数 |

注意：现在**恢复旧的运行可能触发续算**，不再等同于"只重新做后处理"。
