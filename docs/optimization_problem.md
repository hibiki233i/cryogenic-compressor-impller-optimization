# 优化问题说明

本文用通俗的语言说明：这个项目到底在优化什么、有哪些限制、数据是怎么约定的。
想直接跑一遍示例，请看 [离线复现指南](../examples/offline/README.md)。

## 要解决的问题

在一个**固定的工况**（出口静压默认 12 Pa）下，调整叶轮的 13 个几何参数，
同时让两个指标尽可能高：

1. **效率**：压缩过程的等熵效率，越高越好。
2. **总压比**：出口与进口的总压之比，越高越好。总压比没有上限或下限要求。

两个目标通常此消彼长，所以结果不是一个"最优解"，而是一组"没有哪个设计在两项上都全面胜出"的设计，
称为**帕累托前沿**。最后由工程指标排序，推荐其中几个。

### 13 个几何参数

下表按常见命名给出大致含义，精确定义以 CFturbo 模板为准。

| 参数 | 含义 |
|---|---|
| d1s、dH | 进口的外径和轮毂直径 |
| beta1hb、beta1sb | 进口叶片角（轮毂侧、外缘侧） |
| d2、b2 | 出口直径和出口宽度 |
| beta2hb、beta2sb | 出口叶片角（轮毂侧、外缘侧） |
| Lz | 轴向长度 |
| t | 叶片厚度 |
| TipClear | 叶顶间隙 |
| nBl | 叶片数，只能取 9、10、11、12 |
| rake_te_s | 出口边外缘的倾斜角 |

各参数的取值范围见离线复现指南中的变量表。程序界面"DOE"页也可以修改。
尺寸沿用 CFturbo 模板的单位，角度以度为单位。

### 出口静压不是设计变量

出口静压是**工况**，不是要优化的几何量。DOE 和主动学习共用同一个固定值，模型把它当作第 14 个输入，
但搜索时不会去改它。基于实际数据挑选设计时，只会采用静压在设定值附近（默认容许偏差 0.25 Pa）的样本，
不把整张工作特性图的数据混进来。

## 限制条件

**流量：** 质量流量不能低于 3.6 g/s。流量不足但已收敛的样本不会被丢掉，
会带上"边界样本"的标记继续参与训练，但不与"运行失败"混为一谈。

**几何规则（硬限制）：** 候选设计必须满足下面这些，否则直接排除：

- d2 与 d1s 的差值不小于 0.070
- 进口叶片角之差（beta1hb 与 beta1sb）不超过 52 度
- 出口叶片角之差不超过 13.5 度
- 出口宽度、厚度、叶顶间隙、轴向长度、rake_te_s 等都在各自的取值范围内（rake_te_s 的范围是 −25 到 −15 度）

这些数值都是可以在界面或配置文件里修改的工程参数，不是固定不变的。

**可靠性要求：** 候选设计还需要通过两项由模型估计的概率检查：求解成功的可能性不低于 0.65，
几何可生成的可能性不低于 0.55。预测效率需要在 0.60 到 0.84 之间。

**软限制：** 除了上述硬限制，搜索时还会对"模型把握不大"和"几何不够安全"的设计做扣分。
另外，rake_te_s 有一个随叶片数变化的参考下限：9、10、11、12 片分别为 −18、−19、−20、−21 度。
低于它的设计**不会被排除**，只是按低出多少被扣分，所以最终结果里仍可能出现低于参考下限的设计，需要自行留意。
这些扣分使优化倾向于选择更稳妥的设计，是倾向，不是禁止。

## 总压比的口径

总压比统一采用**静止坐标系下质量流量平均的总压比**（出口平均总压 ÷ 进口平均总压）。
这是数据格式的"第 2 版"约定。

旧版本留下的结果文件、训练数据表、固定测试集和主动学习检查点，如果没有带上对应的口径标记，
程序会拒绝使用。处理办法：用界面的"恢复运行结果"从已有的 `.res` 文件重新提取，
再重新训练模型、重新计算帕累托前沿。

## 数据和模型文件

| 文件 | 说明 |
|---|---|
| 训练数据表（CSV） | 每行一个已完成的 CFD 算例：13 个几何参数、出口静压和各项结果。旁边有 `.meta.json` 记录口径 |
| 固定测试集 | 从数据中留出的一部分（约 15%），只用来检验模型，不参与训练 |
| 模型权重、两个归一化器 | 模型和它配套的输入/输出归一化器必须成对使用 |
| `surrogate_model_manifest.json` | 记录模型与归一化器的指纹、变量顺序和所用数据，防止错配 |
| `design_variables.json` | 界面保存的各变量取值范围 |
| `failure_records.csv` | 所有运行结果（含失败原因）的记录 |

查询帕累托前沿时使用与模型配套的归一化器，不再根据查询数据重新拟合。
旧的、或所依据数据已变的前沿缓存不能直接导出，需要先重新计算。

## 优化引擎的做法（简述）

1. 用 DOE 得到初始数据，训练预测模型（预测效率、总压比和流量）。
2. 用多目标遗传算法（NSGA-II）在模型上大范围搜索，得到预测的帕累托前沿。
3. 从候选里挑选最有价值的几个设计，用真实 CFD 验证（主动学习，详见 [主动学习说明](active_learning.md)）。
4. 验证结果补充进数据，重新训练，进入下一轮。
5. 达到设定的迭代次数、或前沿质量（超体积）长时间不再提升时停止。

最终排序采用工程评分，综合考虑效率余量、流量余量、前沿拐点位置、几何安全概率、
与已成功样本的距离以及稳定性。**这个排名仅用于推荐，不能替代效率—总压比的前沿本身**，
最后仍需 CFD 验证。
