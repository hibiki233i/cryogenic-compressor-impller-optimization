# 更新记录

按时间由新到旧整理。想了解各功能现在怎么用，请看 [使用指南](user_guide.md)；
这里只记录"什么时候增加了什么、有什么影响"。

## 2026-09：清理样本后的主动学习与收敛验收

- **仅用初始数据的对照基准**：界面里的"仅 DOE 的 NSGA-II 基准"默认只用清理后的初始数据，不读主动学习样本。
  详见 [主动学习说明](active_learning.md)。
- **模型文件校验**：模型与两个归一化器随附一份清单，记录指纹、变量顺序和所用数据；
  帕累托查询使用配套的归一化器。旧的或数据已变的前沿缓存不能直接导出，须重新计算。
- **独立的主动学习实验**：新增 `prepare_al_stage.py`，可建立相互隔离的实验阶段，并输出可用于论文的真实超体积曲线。
- **CFX 残差验收与自动续算**：所有求解入口在后处理前检查残差，未达标自动用结果文件续算。
  详见 [CFX 收敛检查与续算](cfx_convergence.md)。
- **自动测试**：每次提交运行语法检查、全部测试和离线复现，最低支持 Python 3.11。

## 界面更新

### 数据分析与算例浏览（Ctrl+8、Ctrl+9）

新增两页，均用原生表格和图表，不嵌入网页，也不重新运行模型。可筛选数据、对比预测与实际值、查看交叉验证记录，
逐个翻阅算例、预览文件，并可打开另一个实验的结果做只读查看。不改变采集和验证的方法、数据格式、模型，
已有模型无需重新训练。

### 实时结果（Ctrl+7）

新增实时结果页，每 3 秒读取已保存的数据，显示样本数、最高效率与总压比、散点图和超体积曲线。
只读文件，不启动额外求解，也不读取 CFX 内部的逐步残差。

### 界面外观

采用深色的工程控制台风格，青绿色作为主要操作按钮的颜色。保留六步工作流，`Ctrl+1` 到 `Ctrl+6`
切换工作流页面。小窗口下表单可滚动，工程阈值和任务动态区可折叠；任务状态同时用文字和颜色表示。
中英文的导航、标题和提示同步切换。这次调整不影响求解、数据格式、固定出口压力或模型兼容性。

## 更早的变化

- 出口静压从"可调范围"改为 DOE 与主动学习共用的固定工况值（默认 12 Pa）。
- 总压比改用静止坐标系口径（数据格式第 2 版），旧数据须重新提取（见 [优化问题说明](optimization_problem.md)）。
- 每轮主动学习输出模型验证记录，并采用一致的随机预测分布完成筛选、排序和记录。
- 增加失败记录机制，区分软件故障与设计本身不可行。
- 桌面程序自动保存路径和运行设置，下次启动自动读回。
- 增加解析合成数据的离线复现示例，可在无 CFD 软件的环境验证流程。
